# Contributing

Thank you for helping make focused operational software easier to own and adapt.

1. Open an issue describing the workflow or invariant before a large change.
2. Keep business behavior in `@crm-library/core` and use the operation path from every client.
3. Add tests for state transitions, authorization, idempotency, and audit events.
4. Keep agent tools task-shaped and narrower than the raw operation catalog.
5. Preserve complete export and Cloudflare-free domain imports.
6. Run `pnpm check` before opening a pull request.

Do not commit real participant data, credentials, copied proprietary interfaces, or assets without
clear redistribution rights.
