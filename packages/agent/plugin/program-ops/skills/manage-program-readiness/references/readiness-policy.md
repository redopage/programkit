# Readiness policy

- `approved` and `waived` satisfy a requirement.
- `submitted` awaits human review; it is not complete.
- `revision_requested` is a blocker and should state the requested correction when available.
- `not_started` is a blocker only when the requirement applies to the participant.
- Invitation confirmation and session acceptance are independent states.
- Never include declined, withdrawn, suppressed, or already-complete participants in reminders.
- Group reminders by a coherent next action; do not send one vague catch-all message.
- A campaign draft may be created by the agent. Approval and delivery remain human-only.
