# Matching rules

Use strongest identifiers first:

1. Stable external source ID plus source system
2. Verified email address
3. Exact normalized email alias known to the existing record
4. Name plus organization plus corroborating title or location

Treat shared addresses, assistants representing multiple people, name-only matches, and conflicting
external IDs as ambiguous. Preserve the source row identifier and proposed decision for every row.
Merging people must remain a separate human-approved operation.
